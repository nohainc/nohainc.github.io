Tutorial

Learn Nano Markup.

Nano Markup has three value types and a small set of syntax rules. This tutorial shows the practical basics for writing and reading a .nano file.

Basics

Start with mappings and sequences

A document can be a string, a mapping, or a sequence. A root mapping begins with ... A root sequence begins with :. Nested values use exactly four spaces per level.

..
    title Project notes
    tags:
        release
        documentation
    owner..
        name Ariana
        team Tools

Text

Use block strings for multiline text

Use | when a value spans multiple lines. The block body is indented one level deeper than the key.

..
    summary|
        Nano Markup is small.
        It keeps plain text readable.
    status stable
